1. What This System Does

This is a backend automation layer that connects Monday.com with several external services. It runs entirely on Vercel (serverless) with no server to maintain. Everything is triggered by webhooks — when something changes in Monday or in an external form, a function runs automatically.

#TriggerAction
1Customer submits Typeform (flight info)Updates their Monday item on Board 2 with the flight data
2Staff sets Monday status to "Event Created"Creates a Google Calendar event on the correct calendar
3Staff sets Monday status to "Email X sendt"Sends a customer email with the correct template & PDFs
4Daily at 07:00 UTC (automatic)Sends Email 4 to Board 3 patients whose surgery is within 14 days
5Customer submits Meta lead formCreates a new Monday item with the lead's details
6Customer submits WPForms (WordPress)Creates a new Monday item with the form data
Three Monday boards are in use:
Board 1 — 5052697723 (Nye leads / Sally)
Board 2 — 5089650058 (Zari's board)
Board 3 — 5052958230 (Aftercare / surgery patients)

4. Integration 1 — Typeform → Monday
Customer fills Typeform
→
POST to /api/webhook
→
Find item by email on Board 2
→
Update columns + post comment

What it does step by step

  1. Customer fills out a Typeform — the flight information form
  2. Typeform sends a POST request to /api/webhook
  3. The code reads all answers and extracts the customer's email address
  4. It searches Monday Board 2 for an item where the email column (email_mkza7v62) matches
  5. Updates all mapped columns on the item (arrival time, flight numbers, etc.)
  6. Always sets two extra columns: color_mm0x1y1w → "Yes" (form submitted) and color_mkzbweje → "Email 3 sendt" (which triggers Email 3 automatically)
  7. Posts a comment on the Monday item confirming submission
Idempotency: A Redis key tf_token:{token} is set after processing. If Typeform retries (it does this automatically on network errors), the duplicate is silently ignored.

Where to configure in Typeform

Typeform → the form → Connect → Webhooks → add URL: https://typeform-monday-webhook.vercel.app/api/webhook

Failsafe design

  • Atomic lock: Redis SET NX (set-if-not-exists) claims a lock before sending. If Monday fires the webhook twice simultaneously, only one attempt wins the lock — the other is silently rejected as a duplicate.
  • 3-attempt retry: If Gmail fails, the code retries twice more (1.5s then 3s delay). Only after all 3 failures does it give up.
  • Lock released on failure: If all 3 attempts fail, the lock is deleted so a staff member can hit "Resend" in the dashboard to try again.
  • Monday comment: After every successful send, a comment is posted on the item: "✉️ Email X sendt, [time], Status: Sendt ✓"

Where to configure in Monday

Each board → Integrate → Webhooks → register /api/monday-email for "When column changes" on the email status column for that board.

7. Integration 4 — Auto Email 4 (14-day cron)
07:00 UTC every day
→
Vercel calls /api/email-cron
→
Check all Board 3 items
→
Surgery within 14 days?
→
Send Email 4 (if not already sent)

This runs without any staff action. 14 days before a patient's surgery date (column date_mkxmb3rn on Board 3), Email 4 is sent automatically. The same Redis lock system prevents double-sends.

If sending fails one day, the lock is released and the next day's cron retries. Once sent, the lock persists for 30 days — so changing the date does not accidentally re-send.

Schedule configuration

Defined in vercel.json at the root of the repository:

{ "crons": [{ "path": "/api/email-cron", "schedule": "0 7 * * *" }] }

Change "0 7 * * *" to any cron expression to adjust the time. 0 7 * * * = 07:00 UTC every day.

8. Integration 5 — Meta Leads & WPForms

Meta Leads (/api/meta-webhook)

When a customer submits a Facebook/Instagram lead form, Meta sends a POST to /api/meta-webhook. The code fetches the full lead data from the Meta Graph API, creates a Monday item, and logs it. A Redis key meta_lead:{leadId} prevents duplicate items.

Where to configure: Meta Business Suite → Webhooks → subscribe to leadgen events on your Facebook Page → set URL to /api/meta-webhook and the verify token to the value of META_WEBHOOK_VERIFY_TOKEN.

WPForms (/api/wpforms-webhook)

When a customer submits a form on the WordPress site, WPForms sends a POST to /api/wpforms-webhook. The code maps form fields to Monday columns and creates an item.

Where to configure: WordPress admin → WPForms → the form → Settings → Webhooks → add URL /api/wpforms-webhook.

To add a new PDF: Upload to Blob → copy the URL → add it to the attachments array in lib/emailConfig.js → push to GitHub.

The dashboard is a static HTML file at public/index.html served at the root URL. It polls the API every 10 seconds and shows live data.

11. Common Issues & Fixes
ErrorCauseFix
invalid_grant in Email tab Google OAuth refresh token expired. Happens every 7 days when the OAuth app is in "Testing" mode. 1. Publish the Google OAuth app (Google Cloud Console → APIs & Services → OAuth consent screen → Publish App) — tokens no longer expire after 7 days.
2. Generate a new refresh token: go to OAuth Playground → gear icon → use your own credentials → select scopes gmail.send + calendar → authorize as the sending account → exchange for tokens → copy refresh_token.
3. Update GOOGLE_REFRESH_TOKEN in Vercel env vars → Redeploy.
Emails not triggering at all Monday webhook not registered for that board Monday → the board → Integrate → Webhooks → add /api/monday-email on "When column changes" for the email status column
Calendar events not creating Monday webhook not registered, or wrong column ID Register /api/calendar-webhook in Monday for both the status and date columns. Column IDs are shown in the Calendar tab of the dashboard.
Duplicate emails received Was a race condition in old code (now fixed) Already fixed with Redis SET NX atomic locking. If it reappears, check that KV is connected in Vercel Storage.
Deployment fails after adding a file to api/ Exceeded 12-function limit on Hobby plan Delete another function from api/, or upgrade to Vercel Pro plan.
Typeform not finding Monday item Email in Typeform doesn't match email in Monday The item is searched by column email_mkza7v62 on Board 2. Ensure the email exists in Monday before the form is submitted.
Email 4 not sending automatically CRON_SECRET missing, or cron not running Check Vercel → Settings → Environment Variables for CRON_SECRET. Check Vercel → Cron Jobs tab to confirm it's scheduled and last ran successfully.
