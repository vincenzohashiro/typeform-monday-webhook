1. Project Overview

This is a custom-built automation system for Håreksperten, a Danish hair transplant company. It acts as a central hub that connects the company's various lead sources and tools to their project management software, Monday.com.

Think of it as a switchboard: whenever a potential client fills out a form, triggers an action in Monday, or gets close to their operation date, this system automatically handles the follow-up — creating records, sending emails, booking calendar events — without anyone needing to do it manually.

It runs 24/7 on Vercel (a cloud hosting platform) and is accessible at:

Live dashboard URL https://typeform-monday-webhook.vercel.app

What problems does it solve?

  • Leads from Facebook/Instagram ads are automatically added to Monday — no manual copy-pasting
  • Website contact form submissions go directly to Monday — no manual entry
  • When a client submits their flight details via Typeform, their Monday record is updated instantly
  • Calendar events for client appointments are created, updated, and deleted automatically
  • Emails with PDF attachments are sent automatically when team members change a status in Monday
  • Email 4 for Board 3 is sent automatically 14 days before each client's operation date — no one needs to remember

3. Integration 1: Typeform → Monday

When a client fills out the Typeform flight information form, their details are automatically matched to their existing record in Board 2 in Monday and all relevant columns are updated.

Step-by-step flow

Client submits Typeform
→
Typeform POSTs to /api/webhook
→
System finds client in Board 2 by email
→
Updates all Monday columns
→
Sets status to "Email 3 sendt"
→
Posts comment on Monday item
→
Logs to dashboard

Fields mapped to Monday

The system reads answers from the Typeform response and maps them to the corresponding Monday columns on Board 2.

Duplicate prevention

Typeform assigns a unique token to every submission. The system saves this token after processing. If Typeform retries the same submission (which it does automatically on network errors), the system recognises the token and ignores the duplicate.

What triggers an error

  • No email address in the Typeform response → cannot search Monday
  • Email not found in Monday Board 2 → person may not have been created yet
  • Monday API temporarily unavailable → system returns 500 so Typeform retries
Webhook endpoint POST https://typeform-monday-webhook.vercel.app/api/webhook

Keeps Google Calendar automatically in sync with Monday. When a team member sets an appointment date and changes a status in Monday, a calendar event is created. Date changes update the event. Setting the status to "Event Delete" removes it.

Trigger labels

Status set in MondayWhat happens
Event CreatedCalendar event is created using the date column and client details
Event DeleteThe calendar event is deleted

Date changes

If someone changes the date column on a Monday item that already has a calendar event, the calendar event is automatically updated to match the new date — no need to delete and recreate it.

Smart edge case handling

  • Monday fires twice: The system recognises the duplicate and ignores it (logged as "Deduplicated")
  • Calendar event manually deleted: If someone deletes the event from Google Calendar directly and then triggers it again from Monday, the system detects it's gone and creates a fresh one
  • Date set before status: If the status is set to "Event Created" but there's no date yet, the system logs "no date set on item" and does nothing

The 14-day automatic timer (Email 4 only)

A daily cron job runs every morning at 07:00 UTC. It checks every item on Board 3 and looks at the "Operationsdato" column (operation date).

  • If the operation date is 14 days or fewer away and Email 4 has not been sent yet → it sends Email 4 automatically
  • If Email 4 was already sent (manually or by the timer) → it is skipped
  • If the email fails today → the lock is released, and tomorrow's run tries again
  • This continues every day until the email succeeds or the operation date passes
Result: Every Board 3 client will receive Email 4 within the 14-day window before their operation, regardless of whether anyone in the team remembers to send it manually.

Duplicate prevention (all emails)

Monday often fires webhooks 2–3 times per status change. To prevent the same email being sent twice:

  • The moment the system decides to send, it claims an atomic lock in the database
  • Any second webhook that arrives — even milliseconds later — sees the lock is taken and stops immediately (logged as "Duplicate")
  • If the send fails, the lock is released so the next attempt can go through
  • The lock expires after 30 days automatically
Webhook endpoint POST https://typeform-monday-webhook.vercel.app/api/monday-email
Cron endpoint GET https://typeform-monday-webhook.vercel.app/api/email-cron (runs daily at 07:00 UTC)

8. Monday Webhooks — Complete Reference

A webhook is a notification that Monday sends to this system whenever something changes. Every time a relevant status or date column is changed in Monday, Monday instantly sends the details to the corresponding endpoint URL. Without these webhooks registered in Monday, none of the automations fire.

How to register a webhook in Monday
Open the board → click Integrate (top right) → search "Webhooks" → choose trigger "When a column changes" → select the column → paste the URL → save.

10. Technical Infrastructure

⚡ Vercel (Hosting)

Runs the entire system on the cloud. Each endpoint is a serverless function — it starts when a request arrives and shuts down when done. Vercel Hobby plan: max 12 functions (project is at exactly 12).

🗄 Vercel KV (Database)

A fast in-memory database (Redis). Stores event logs, duplicate-prevention locks, calendar event references, and reset timestamps. Logs keep the last 200 entries per integration.

📁 Vercel Blob (File storage)

Stores the 6 PDF attachments privately. Files are not publicly accessible — the system fetches them using a secret token when building emails.

📅 Monday.com API

Used to create items, update columns, post comments, read column values, and fetch item details. Includes automatic rate-limit retry with exponential backoff.

✉️ Gmail API (Google OAuth2)

Sends emails from info@haareksperten.com. Uses a long-lived refresh token so it never needs a password re-entry. Scopes: gmail.send + calendar.

📆 Google Calendar API

Creates, updates, and deletes events on three separate Google Calendar accounts (one per board). Uses the same Google OAuth2 credentials as Gmail.

Vercel — The Hosting Platform

URL vercel.com → log in → vincenzohashiros-projects → typeform-monday-webhook

1. Deployments

Shows every time the system was updated. Each deployment has a status: Ready (working), Building (in progress), or Error (failed — click to see why).

To redeploy manually: Click ··· next to a deployment → Redeploy. Required after changing environment variables.

2. Environment Variables (Settings → Environment Variables)

The secret keys the system needs to connect to external services. Never stored in the code — kept here, encrypted.

To edit: Click the variable → pencil icon → change value → Save → then redeploy.

Always redeploy after changing any environment variable. The running system does not automatically pick up the new value until redeployed.

3. Logs

Shows everything the system does — every request, error, and response. The main diagnostic tool.

  • Set timeline to Last 30 minutes when investigating a recent issue
  • Search for an endpoint name (e.g. monday-email) to filter results
  • Click any entry to see full details in the right panel
  • Click Live to watch requests arrive in real time
  • Use the Error checkbox to show only failing requests

4. Cron Jobs

Shows the daily email timer for Board 3. The job /api/email-cron runs every day at 07:00 UTC (09:00 Danish summer time). You can click Run to trigger it manually for testing.

Vercel Blob — PDF File Storage

Where: Vercel dashboard → Storage → Blob

Stores the 6 PDF attachments privately. To add or replace a PDF:

  1. Go to Vercel → Storage → Blob
  2. Click Upload and select the PDF
  3. Copy the URL it gives you
  4. Give the URL to a developer to update the email config in the code
Uploading a file to Blob alone does not attach it to any email. A developer must update the code in lib/emailConfig.js to reference the new URL.

Vercel KV — The Database

Where: Vercel dashboard → Storage → KV

The database that stores all logs and duplicate-prevention locks. You generally do not need to touch this — the dashboard already shows the data in readable form. Only access it directly if you need to manually delete a stuck lock to force a resend.
